BAHA BARLA — УСТАНОВКА В МАГАЗИНЕ
==================================

Что это
-------
Телефоны с приложением Baha barla ищут товар в базе akhasap.
Телефон не подключается к SQL Server напрямую: он обращается к службе
Baha barla, а служба уже подключается к SQL Server.
Служба ставится на тот же компьютер, где стоит SQL Server.

    Телефон  --Wi-Fi-->  компьютер с SQL Server (служба Baha barla, порт 8080)

Требования
----------
- Windows 10 или Windows 11 на компьютере с SQL Server.
- Телефоны подключены к той же сети (Wi-Fi), что и этот компьютер.
- Этот компьютер должен быть включён, пока работают телефоны.
- Устанавливать .NET и другие программы не нужно — всё уже в папке.

Содержимое архива
-----------------
  install.cmd        — установка службы
  uninstall.cmd      — удаление службы
  BahaBarlaApi\      — сама служба (не открывать, не менять)
  app-release.apk    — приложение для телефонов
  INSTRUKCIYA.txt     — этот файл


ШАГ 1. Установить службу
------------------------
1. Скопируйте архив на компьютер с SQL Server и распакуйте его целиком
   (например, на рабочий стол).
2. Дважды щёлкните install.cmd и разрешите запуск от имени администратора.
3. На вопросы можно просто нажимать Enter:
     Адрес SQL Server  [localhost]  — если SQL Server на этом компьютере.
                                      Именованный экземпляр указывается так:
                                      localhost\SQLEXPRESS
     Порт для телефонов [8080]
4. В конце появится адрес компьютера, например 192.168.1.25.
   Запишите его: этот адрес вводится на телефонах.

Служба запускается сама при включении компьютера.
Чтобы переустановить службу или сменить настройки, снова запустите install.cmd.


ШАГ 2. Создать логины сотрудников в SQL Server
----------------------------------------------
На телефоне каждый сотрудник входит под своим логином SQL Server.
Какие базы он увидит, решают права этого логина.
Пароль sa сотрудникам не выдавайте.

В SQL Server Management Studio (SSMS):

1. Security -> Logins -> правой кнопкой -> New Login...
   - Login name: например ali
   - Выберите SQL Server authentication, задайте пароль.
   - Снимите галочку "User must change password at next login".
2. Слева откройте страницу User Mapping:
   - Отметьте галочкой базы, которые сотруднику можно видеть.
   - Для каждой отмеченной базы внизу поставьте роль db_datareader.
3. Нажмите OK.

Если сотрудник должен менять фото товаров с телефона:
   Databases -> нужная база -> Tables -> dbo.tbl_mg_images ->
   правой кнопкой -> Properties -> Permissions -> Search -> выберите
   пользователя -> поставьте Grant у Insert и у Update.

Если вход по логину не работает вообще:
   правой кнопкой на сервере в SSMS -> Properties -> Security ->
   должно быть "SQL Server and Windows Authentication mode".
   После изменения перезапустите службу SQL Server.


ШАГ 3. Установить приложение на телефоны
----------------------------------------
1. Перенесите app-release.apk на телефон и откройте его.
   Если телефон спросит, разрешите установку из этого источника.
2. Откройте приложение. Сразу откроется экран Settings:
     Server Address — адрес компьютера из шага 1 (например 192.168.1.25)
                      (если при установке выбран порт не 8080, укажите
                      его через двоеточие: 192.168.1.25:8090)
     Database Name  — имя базы, например akhasap_db_magazin
     User Name      — логин сотрудника из шага 2
     Password       — его пароль
3. Нажмите SAVE SETTINGS. Приложение проверит логин и запомнит пароль.
   Кнопка LOG OUT стирает логин и пароль, чтобы на телефоне мог работать
   другой сотрудник.


ЕСЛИ НЕ РАБОТАЕТ
----------------
"Cannot reach the server"
  - Телефон в другой сети (гостевой Wi-Fi, мобильный интернет) или на нём
    включён VPN.
  - Компьютер со службой выключен.
  - Проверка: откройте в браузере телефона http://АДРЕС:8080/health
    Должно появиться {"ok":true,...}.

"Login failed. Check user name and password."
  - Неверный логин или пароль, либо не включён режим
    "SQL Server and Windows Authentication mode" (см. шаг 2).

"This login has no access to the database"
  - У логина не отмечена эта база в User Mapping или нет роли db_datareader.
  - Или имя базы на телефоне написано с ошибкой.

Страница /health открывается, но товары не ищутся, "Cannot reach the server"
  - Не запущен SQL Server: Win+R -> services.msc -> "SQL Server (...)" ->
    Состояние "Выполняется", Тип запуска "Автоматически".
  - Выключен протокол TCP/IP: SQL Server Configuration Manager ->
    SQL Server Network Configuration -> Protocols -> TCP/IP -> Enabled,
    затем перезапустить службу SQL Server.

Адрес компьютера поменялся (телефоны перестали подключаться)
  - Узнать новый: Win+R -> cmd -> ipconfig -> "IPv4-адрес".
  - Чтобы адрес больше не менялся, закрепите его за компьютером в
    настройках роутера.


Удаление
--------
Запустите uninstall.cmd. Базы данных SQL Server при этом не затрагиваются.
